# Translation Decisions Reference

Consult this reference during **Step 2** of every translation to resolve open linguistic variables before drafting Tigrinya text.

---

## 1. Dialect Default

* **Default:** Standard written **Eritrean Tigrinya** (Asmara school, press, and civic standard).
* **Rule:** Do not switch to Tigray Tigrinya unless the user explicitly requests Tigray usage.
* **Lexical standards for Eritrean default:**
  * Use **ሕጂ** (*ḥəǧi* - now), not *ሕዚ* (*ḥəzi*).
  * Use **ኣብ** (*ab* - in/at/on) and **ናብ** (*nab* - to/towards).
  * Use **ድማ** (*dəmba*) or **ኸኣ** (*xä'a*) for "also/furthermore".
  * Keep spelling of look-alike letters consistent across the whole output.

---

## 2. Register & Politeness

Tigrinya distinguishes social distance and honorific status grammatically through pronominal and verbal inflection:

| Addressee Context | Pronoun (m.) | Pronoun (f.) | Verb Agreement | Example ("Please sit down") |
| :--- | :--- | :--- | :--- | :--- |
| **Familiar / Peer / Child** | ንስኻ (*nəsxa*) | ንስኺ (*nəsxi*) | 2nd person singular | ኮፍ በል (*kof bäl* m.) / ኮፍ በሊ (*kof bäli* f.) |
| **Polite / Respected / Elder / Stranger** | **ንስኹም** (*nəsxum*) | **ንስኽን** (*nəsxən*) | **2nd person plural** | **ኮፍ በሉ** (*kof bälu*) / **ተቐመጡ** (*täqämäṭu*) |
| **Respected 3rd Person (Honorific)** | **ንሶም** (*nəsom*) | **ንሰን** (*nəsän*) | **3rd person plural** | **መምህር መጺኦም** (*mämhər mäṣi'om*) |

### Application Rules:
1. **Polite Singular:** When addressing a single elder, teacher, official, clergy member, or unfamiliar adult, use the polite singular pronouns (**ንስኹም / ንስኽን**) with matching **plural verb endings**.
2. **Consistency:** Never mix familiar singular and polite plural forms in the same text or paragraph.

---

## 3. Resolving English "You"

English "you" obscures gender, grammatical number, and politeness. Resolve it systematically:

1. **Short text / Single sentence:**
   * If the context does not specify the addressee, either ask the user for clarification before translating or provide the primary readings clearly labeled:
     * *(Familiar masculine)*
     * *(Familiar feminine)*
     * *(Polite singular)*
2. **Long text / Multi-sentence document:**
   * Determine the most probable reading from the broader domain and context.
   * Explicitly state the chosen reading in the notes.
   * Maintain that exact choice consistently across the entire text.
