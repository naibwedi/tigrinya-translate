# Tigrinya (Geʽez) to Latin Transliteration Guide

This reference defines the standard phonetic and Latin transliteration scheme for Tigrinya Fidel characters, labiovelars, numerals, and punctuation.

---

## 1. Primary Syllabary (The 7 Orders)

Each base consonant has seven orders representing vowel modifications:
1. **1st Order (ግዕዝ - Gəʼəz)**: /ä/ or /e/ (e.g., *he*, *le*)
2. **2nd Order (ካዕብ - Kaʼəb)**: /u/ (e.g., *hu*, *lu*)
3. **3rd Order (ሣልስ - Saləs)**: /i/ (e.g., *hi*, *li*)
4. **4th Order (ራብዕ - Rabəʼ)**: /a/ (e.g., *ha*, *la*)
5. **5th Order (ኃምስ - Haməs)**: /e/ or /ie/ (e.g., *hie*, *lie*)
6. **6th Order (ሳድስ - Sadəs)**: /ə/ or consonant only /∅/ (e.g., *h*, *l*)
7. **7th Order (ሳብዕ - Sabəʼ)**: /o/ (e.g., *ho*, *lo*)

## 2. Labiovelar Series (ዲፕቶንግታት / ውህደት ድምጽታት)

Labiovelar characters combine a velar consonant with an rounded /w/ element:

| Series | 1st (we) | 3rd (wi) | 4th (wa) | 5th (wie) | 6th (w) |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Q-Series** | ቈ (qwe) | ቊ (qwi) | ቋ (qwa) | ቌ (qwie) | ቍ (qw) |
| **Qh-Series** | ዀ (Qwe) | ዂ (Qwi) | ዃ (Qwa) | ዄ (Qwie) | ዅ (Qw) |

## 4. Punctuation Marks (ስርዓተ ነጥቢ)

| Symbol | Name | Function / Latin Equivalent |
| :--- | :--- | :--- |
| **።** | ዓራት ነጥቢ (Arat Netbi) | Full stop / Period (`.`) |
| **፣** | ንኡስ ነጥቢ (Nius Netbi) | Comma (`,`) |
| **፤** | ድርብ ሰረዝ (Dirib Serez) | Semicolon (`;`) |
| **፦** | ነጥቢ መብርሂ (Netbi Mibrihi) | Colon (`:`) introducing quotes, lists, or direct speech |
| **፧** | ሕቶ ነጥቢ (Hito Netbi) | Question mark (`?`) |
| **፨** | ይትበሃል (Yitbehal) | Section or paragraph break marker |
