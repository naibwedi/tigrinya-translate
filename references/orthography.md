# Tigrinya Orthography, Punctuation, & Latin Transliteration Standard

Consult this reference whenever writing Tigrinya Geʽez text or generating the Latin pronunciation guide.

---

## 1. Traditional Geʽez Punctuation (ስርዓተ ነጥቢ)

Always prioritize Geʽez punctuation in standard Tigrinya text:

| Mark | Name | Function / Latin Equivalent |
| :--- | :--- | :--- |
| **።** | ዓራት ነጥቢ (*Arat Netbi*) | Sentence terminator / period (`.`). Never place a comma immediately before it. |
| **፣** | ንኡስ ነጥቢ (*Nius Netbi*) | Clause separator / comma (`,`). |
| **፤** | ድርብ ሰረዝ (*Dirib Serez*) | Semicolon (`;`). Separates connected independent clauses. |
| **፦** | ነጥቢ መብርሂ (*Netbi Mibrihi*) | Colon (`:`). Introduces quotations, dialogue, or lists. |
| **፧** | ሕቶ ነጥቢ (*Hito Netbi*) | Question mark (`?`). (Latin `?` is also common in casual text). |

For translated prose produced under this skill, use **፧** rather than the Latin question mark.

## 2. Fidel Selection & Look-Alike Consistency

Maintain orthographic consistency across the entire document:

### A. The Pharyngeal vs Glottal: ዐ vs አ
* Distinct phonetic sounds and meanings in Tigrinya:
  * **ዓለም** (*‘aläm* = world) vs mispelled *ኣለም*
  * **ዕዮ** (*‘əyo* = work) vs *እዮ* (*əyyo* = they are)
  * **ዓይኒ** (*‘ayni* = eye) vs mispelled *ኣይኒ*
  * **ኣቦ** (*abo* = father) vs incorrect *ዓቦ*

### B. The S-Letters: ሰ vs ሠ
* Use **ሰ** (*se*) for general vocabulary (*ሰላም, ሰብ, ሰበረ*).
* Retain **ሠ** (*se*) only in classical ecclesiastical terms (*ሥጋዌ, ሥላሴ, ሥርዓት*).

### C. The Ts-Letters: ጸ vs ፀ
* Use **ጸ** (*tse*) for standard Tigrinya (*ጸሎት, ጸሓፈ, ጸሓይ*).
* Retain **ፀ** (*tse*) only in classical Geʽez liturgical phrases (*ዕፀ ጳጦስ, ፀዋሪተ ፍሬ*).

### D. The H-Letters: ሀ vs ሐ vs ኀ vs ኸ
* **ሀ**: Glottal /h/ (*ሃገር, ሃበ*).
* **ሐ**: Voiceless pharyngeal /ḥ/ (*ሓቂ, ሕጊ, ሓወ*). Distinct and strictly preserved.
* **ኸ**: Velar fricative /x/ (*ኸደ, ረኸበ*).
* **ኀ**: Historical Geʽez letter; written with **ሀ** or **ኸ** in standard modern orthography.

## 3. Latin Transliteration System

To ensure consistency across models, follow this unified Latin phonetic standard:

### A. Vowel Orders
1. **1st Order (ግዕዝ):** **ä** (e.g. *fäläṭä*)
2. **2nd Order (ካዕብ):** **u** (e.g. *kälbu*)
3. **3rd Order (ሣልስ):** **i** (e.g. *mämhər*)
4. **4th Order (ራብዕ):** **a** (e.g. *gäza*)
5. **5th Order (ኃምስ):** **e** (e.g. *bəṣəḥe*)
6. **6th Order (ሳድስ):** **ə** (or consonant only /∅/ when vowel is silent: e.g. *məgbi*, *säb*)
7. **7th Order (ሳብዕ):** **o** (e.g. *aloni*)

### B. Consonant Conventions
* **Ejectives:** Mark with an apostrophe: **t'**, **č'**, **p'**, **k'**, **s'** (or **tṣ** for ጸ).
* **Pharyngeals:**
  * **ሐ** (ḥ) → **ḥ**
  * **ዐ** (ʿ) → **ʿ**
* **Gemination (Consonant Doubling):**
  * Gemination alters meaning in Tigrinya (e.g. *qärräbä* "he brought forth" vs. *qäräbä* "he approached").
  * **Rule:** Double the consonant in Latin whenever it is phonetically geminated (*bäliʿä* has single *l*; *əyyu* has doubled *y*).
* **Hyphens:**
  * Do NOT insert artificial hyphens in normal Latin pronunciation lines (write *näti mägbi bäliʿä*, not *nä-ti mäg-bi bä-li-ʿä*). Use hyphens only in grammatical breakdowns.

## 4. Labiovelar Series & Geʽez Numerals

### Labiovelars
* **Q-Series:** ቈ (*q'wä*), ቊ (*q'wi*), ቋ (*q'wa*), ቌ (*q'we*), ቍ (*q'w*)
* **K-Series:** ኰ (*kwä*), ኲ (*kwi*), ኳ (*kwa*), ኴ (*kwe*), ኵ (*kw*)
* **Kh-Series:** ዀ (*xwä*), ዂ (*xwi*), ዃ (*xwa*), ዄ (*xwe*), ዅ (*xw*)
* **G-Series:** ጐ (*gwä*), ጒ (*gwi*), ጓ (*gwa*), ጔ (*gwe*), ጕ (*gw*)
* **H-Series:** ኈ (*ḥwä*), ኊ (*ḥwi*), ኋ (*ḥwa*), ኌ (*ḥwe*), ኍ (*ḥw*)

### Geʽez Numerals
* **፩** (1), **፪** (2), **፫** (3), **፬** (4), **፭** (5), **፮** (6), **፯** (7), **፰** (8), **፱** (9), **፲** (10)
* **፳** (20), **፴** (30), **፵** (40), **፶** (50), **፷** (60), **፸** (70), **፹** (80), **፺** (90), **፻** (100)
