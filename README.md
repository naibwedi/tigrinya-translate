# English ↔ Tigrinya Translator Skill

A Grok skill for precise, context-aware translation between English and Tigrinya.

## Features

- Enforces correct **SOV** word order
- Accurate verb agreement (person, number, gender)
- Natural, idiomatic output rather than literal calques
- Proper Geʽez script rendering
- Optional Latin transliteration
- Tone / register awareness (formal, polite, casual)
- Support for both directions (English → Tigrinya and Tigrinya → English)

## Installation

Place the `english-tigrinya-translator` folder inside your Grok skills directory (typically `~/.grok/skills/` or the equivalent path used by your environment).

## Structure

```
english-tigrinya-translator/
├── SKILL.md                 # Main skill instructions
├── references/
│   └── grammar-notes.md     # Quick grammar reference
├── assets/                  # Optional assets
└── README.md
```

## Usage

The skill activates automatically when you ask for English–Tigrinya translation, grammar checking, or related tasks. You can also invoke it explicitly.
